# Draw.io Composer Patterns

Use this reference when writing or updating the final `.drawio` composer.

## Minimal Composer Structure

```python
from pathlib import Path
from urllib.parse import quote
import xml.etree.ElementTree as ET

ROOT = Path(__file__).resolve().parent
OUT = ROOT / "figure.drawio"


def style(parts):
    return ";".join(parts) + ";"


def svg_style(rel_path, fixed=True):
    svg = (ROOT / rel_path).read_text(encoding="utf-8")
    parts = [
        "shape=image",
        "html=1",
        "verticalLabelPosition=bottom",
        "verticalAlign=top",
        "imageAspect=0",
        "image=data:image/svg+xml," + quote(svg, safe=""),
    ]
    if fixed:
        parts.append("aspect=fixed")
    return style(parts)
```

## Builder API

The composer should expose small helpers instead of repeated XML literals:

```python
class Builder:
    def __init__(self, width, height, name="Figure"):
        self.mxfile = ET.Element("mxfile", {
            "host": "app.diagrams.net",
            "agent": "Codex",
            "type": "device",
        })
        diagram = ET.SubElement(self.mxfile, "diagram", {"id": "figure", "name": name})
        self.model = ET.SubElement(diagram, "mxGraphModel", {
            "grid": "1",
            "gridSize": "10",
            "guides": "1",
            "tooltips": "1",
            "connect": "1",
            "arrows": "1",
            "fold": "1",
            "page": "1",
            "pageScale": "1",
            "pageWidth": str(width),
            "pageHeight": str(height),
            "math": "1",
            "shadow": "0",
        })
        self.root = ET.SubElement(self.model, "root")
        ET.SubElement(self.root, "mxCell", {"id": "0"})
        ET.SubElement(self.root, "mxCell", {"id": "1", "parent": "0"})
        self.n = 2

    def new_id(self, prefix="c"):
        out = f"{prefix}{self.n}"
        self.n += 1
        return out

    def rect(self, x, y, w, h, cell_style, value="", cid=None):
        cid = cid or self.new_id()
        cell = ET.SubElement(self.root, "mxCell", {
            "id": cid,
            "value": value,
            "style": cell_style,
            "parent": "1",
            "vertex": "1",
        })
        ET.SubElement(cell, "mxGeometry", {
            "x": str(x),
            "y": str(y),
            "width": str(w),
            "height": str(h),
            "as": "geometry",
        })
        return cid
```

## Recommended Helpers

Add these helpers to keep the layout readable:

- `text(x, y, w, h, value, size, color, bold=False, align="center")`
- `image(rel_path, x, y, w, h)`
- `arrow(x1, y1, x2, y2, color="#111111", width="1.2", dashed=False, points=None)`
- `line(x, y, h)` or `vline(x, y, h)` for stage separators.
- `panel_badge(letter, x, y)` for teaser panels.
- `rounded_box(...)` for repeated cards.

## Arrow Rule

Use draw.io edges only for simple connectors:

```python
def arrow(self, x1, y1, x2, y2, points=None):
    cell = ET.SubElement(self.root, "mxCell", {
        "id": self.new_id("e"),
        "value": "",
        "style": style(["endArrow=classic", "html=1", "rounded=0", "strokeWidth=1.4"]),
        "edge": "1",
        "parent": "1",
    })
    geo = ET.SubElement(cell, "mxGeometry", {"relative": "1", "as": "geometry"})
    ET.SubElement(geo, "mxPoint", {"x": str(x1), "y": str(y1), "as": "sourcePoint"})
    ET.SubElement(geo, "mxPoint", {"x": str(x2), "y": str(y2), "as": "targetPoint"})
    if points:
        arr = ET.SubElement(geo, "Array", {"as": "points"})
        for x, y in points:
            ET.SubElement(arr, "mxPoint", {"x": str(x), "y": str(y)})
```

If a connector needs curves, many bends, loops, or custom arrowheads, draw it inside an SVG tile.

## Embedding Existing SVG Panels

Large plot panels can be generated by matplotlib, then embedded into a draw.io page. The draw.io composer should still own:

- Panel titles.
- Badges.
- Separators.
- High-level callouts.
- Legends when the legend must remain editable.

Embed plot tiles only for chart or schematic content that is hard to maintain as draw.io primitives.
